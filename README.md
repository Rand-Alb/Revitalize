# Revitalize - Clinic Management System

Revitalize is a Python-based application that groups multiple medical functions
in an easy to use interface. Users can quickly triage patients, manage patient
records, and log the addition and usage of different supplies from multiple clinics.
Users can have all three windows open at once, allowing access to all three core
functions simultaneously.

## Features
- Patient priority queue based on severity level.
- Patient saving and tracking I/O based on patient information.
- Clinic resources tracker, adding items, logging usage, and alerts with low supplies.
